# Sito principale di B&T App

Questo repository pubblica con GitHub Pages l'indirizzo
**https://formulaunobyedoardoandfabio-del.github.io**.

Serve soprattutto per la pubblicità: AdMob controlla il file
[`app-ads.txt`](app-ads.txt) nella radice del sito indicato nella scheda del
Play Store. Senza questo file verificato le app nuove non ricevono tutti gli
annunci.

- **Non rinominare e non cancellare** questo repository.
- Nella Play Console, nella scheda dello Store, il campo **Sito web** deve
  essere `https://formulaunobyedoardoandfabio-del.github.io`.
- La pagina iniziale porta al sito di B&T App, che si trova nel repository
  `bt-app-flutter` (cartella `docs/`): privacy policy ed eliminazione account.
